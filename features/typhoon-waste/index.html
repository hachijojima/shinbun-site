        台風の災害廃棄物と公費解体

        2026年11月27日（金）更新・第1稿

        2025年10月の台風22号・23号は、八丈島に大量のごみを残した。壊れた家から運び出された家具や家電、建材。全壊して取り壊すしかなくなった建物の廃材。宅地や道に倒れた木と、集められた枝葉である。

        八丈町が2026年8月31日付でまとめた処理の実行計画（第3版）は、処理するごみの量を1万7,604トンと見込む。7月末までに処理を終えたのは2,339トンで、約13%だった。町は当初、2026年12月末にすべてを終えるとしていた。第3版はこの目標を改め、最後に残る倒木と枝葉の完了を2028年3月末とした。

        災害で出たごみは、法律の上では家庭ごみと同じ一般廃棄物で、処理の責任は町にある。ただ、島の焼却炉と船便だけでは手に負えない。計画では量の約7割を島の外へ運び、東京都と東京都環境公社が段取りを受け持って、都内のリサイクル工場や23区の清掃工場で処理する（割合は本紙計算）。費用はいったん町の予算から出し、国の補助と交付税、都の支援で大部分を埋める仕組みになっている。ただし、全体でいくらかかり、最後に町の負担がいくら残るのかは、まだ公表されていない。

        被災した住民が自分で払う場面は限られている。町の許可証があれば、片付けごみは決められた量まで無料で持ち込める。罹災証明で全壊とされた建物は、申請すれば町が公費で取り壊す。

        この特集は、町の処理計画と、町・都・国・東京二十三区清掃一部事務組合の公表資料、町の予算書をもとに、ごみの量、行き先、遅れの理由、解体、費用の順にたどる。数字は2026年11月27日までに公表された資料による。本紙は町の担当課への取材をまだしておらず、取材で得た事実は含まない。発災の経過は「2025年 八丈島の台風22号・23号」が、町の財政の全体は「八丈町の財政を読む」が扱う。

        ごみの中身と、減っていった見込み量

        計画は、災害で出たごみを大きく四つに分ける。

        • 片付けごみ:被災した家から運び出した家具、家電、壊れた建材など
        • 解体廃棄物:全壊した建物を取り壊して出る廃材
        • 枝葉・倒木等:宅地や町道・都道に倒れた木と、住民が持ち込んだ枝葉
        • 土砂:がれきの混じった土

        量の見込みは、計画の版を改めるたびに減った。町が発災後に出した速報値では、土砂を除いて3万6,000トンあった。第3版では1万6,676トンで、半分に満たない。

        数字の動きには、三つの理由がある。

        土砂が計画の外へ出た

        速報値と第1版は、土砂を11万7,000トンと数えていた。都は第1版の公表に合わせて、土砂などは島内での利用を想定していると発表した。町長が2026年3月2日に議会で述べた施政方針も、がれきや倒木類約3万トンと土砂12万トンが仮置場などに集まっているとしている。

        ところが3月31日の第2版から、計画が数える土砂は928トンだけになった。仮置場を元に戻すとき、地面を10センチはぎ取って出る分である。残りの土砂をどこで、どの事業として扱うのか。第3版は書いていない。

        町は2026年6月の補正予算で、道路の災害復旧として堆積土砂排除工事に7,200万円、土砂が流れ込んだ八丈島の海・山・暮らし館の土砂撤去と運搬・整地に計4,279万円を組んだ。これらが11万7,000トンのどれだけにあたるのかは、予算書からは分からない。

        片付けごみは見込みの2倍になった

        第2版は、片付けごみを697トンと見積もった。全壊から準半壊までの建物の数に、1棟あたり1.7トンを掛けた数字である。このとき、一部損壊の建物1,204棟（住家793棟、非住家411棟）は数に入れなかった。2月末までに持ち込まれた量が444トンだったので、多く見積もりすぎないようにしたという。

        実際には、7月末までに1,443トンが持ち込まれた。第3版は、一部損壊の家からも相当な量が出たことが食い違いの原因とみて、見込みを1,749トンに改めた。

        倒木は集まった量で数え直した

        倒木と枝葉は、速報値と第1版で2万1,000トンだった。第3版は推計をやめ、仮置場などに実際に集まった1万632トンを使う。このうち、二次仮置場で処理するのは8,127トンの見込みだ。

        差の分について、計画は次のように書く。置いているあいだに腐葉土のようになった倒木などは、土砂として処分や利用をする。木質バイオマス燃料としての利用も検討する。できるだけ島内で処理し、島外へ運ぶ費用を抑えるためだという。

        どこへ運ばれるか

        ごみは、まず被災した現場から一次仮置場へ運ばれた。燃えるもの、金属、コンクリートなどに分け、島で処理できるものは島で処理する。島で処理できないものは、二次仮置場で選んだり砕いたりしたうえで、コンテナに詰めて船で東京港へ運ぶ。

        町は2025年11月13日、処理の方針を公表した。できる限り島内で処理する。島内で難しいものは、島内で選別や破砕をしてから島外で処理する。分別を徹底し、埋め立てを減らして資源に戻す。島内の処理は島の事業者に任せ、島外への運搬は、八丈島と東京港の間に定期航路をもつ海運業者に任せる。

        なぜ遅れたか

        第3版は、遅れの理由を三つ挙げる。

        一つ目は船である。当初は、2026年1月下旬から都のコンテナを定期の貨物船で運び出し、チャーター船も使って量を増やす計画だった。ところが、チャーター船は想定の週3往復が週2往復になった。海が荒れたときは、安全のため1回に積むコンテナを40基から20基ほどに減らした。想定を超える荒天で欠航も出た。計画した月ごとのペースは保てなかった。

        二つ目は二次仮置場である。倒木の幹や柱は選んで切り、枝葉は砕いてから島外へ出す。その前処理の場所を、2026年4〜5月に造成し、6月から動かす予定だった。しかし4月中旬の入札は、人員と機材が足りず工期内に整備できないという理由で不調に終わった。5月下旬の再入札で事業者が決まり、9月に整備を終える契約を結んだ。その後、表土が想定より厚いことなどから設計を変え、工期を1か月延ばした。整備の完了は10月末、本格的な運営は11月からの見込みとなった。前処理の本格稼働は、約5か月遅れた。

        三つ目は公費解体である。当初は2026年6月に工事を始め、年内に終える計画だった。所有者が島に住んでいないことなどから連絡に手間取り、対象の建物が決まったのは7月末だった。書類の審査にも時間がかかり、着工は当初より4か月遅れる見込みになった。島で解体工事ができる業者は限られ、対象には工場も含まれる。工事の完了は2027年6月の見込みだ。

        町は遅れを取り戻す策を五つ挙げた。8月からの持ち込みを許可証のある人に限り、片付けごみと解体廃棄物を先に片づける。クリーンセンターで燃やす量を増やす。島の事業者のコンテナもチャーター船に積み、都内のリサイクル工場には受け入れ量の上限を緩めることや土曜日の受け入れを求める。島の事業者がふだん使っている柱・角材の搬出の経路も使う。都のコンテナを目標88基で回し、欠航を見込んで船の計画を立て直す。

        どこまで進んだか

        第3版によると、7月末までに仮置場などに集めたか処理を終えたごみは1万4,226トンで、見込みの81%にあたる。このうち処理を終えたのは2,339トンで、13%だった。町の概要版はこれを「8月31日時点」の進み具合として示しているが、計画本体の集計は7月末までの数字である。

        処理を終えた2,339トンのうち、島内で処理したのは1,004トンだった。クリーンセンターで燃やした可燃物が204トン、浅沼組の処分場で受け入れたコンクリートがらが800トンである。島外へ出したのは1,335トンだった。有明興業の若洲工場へは、家具などの混合ごみ422トン、家電4品目を含む金属くず189トン、不燃物52トン、木質類67トン。東京ボード工業へは、柱・角材などの廃木材605トンを出した。

        8月以降の処理量を、町はまとめて公表していない。分かるのは、町が途中で出した数字と、島外の受け入れ先が出している数字である。

        倒壊した家と公費解体

        公費解体は、台風で壊れた建物を、所有者の申請を受けて町が取り壊し、運び出す制度である。費用は町が持つ。すでに自分で業者に頼んで取り壊した人には、かかった費用を町が償還する。

        町の案内によると、対象になるのは次の条件を満たす建物だ。

        • 台風22号か23号で壊れた
        • 罹災証明で全壊と判定された
        • 申請する人が、2025年10月8日時点の所有者か、その相続人である

        家財は前もって運び出しておく。残したものは災害廃棄物として扱われる。電気・ガス・水道を止める手続きは申請者がする。改修のために一部だけを壊す工事は対象にならない。

        町は2026年2月1日に制度の要綱を公表し、4月1日から申請を受け付けた。町の案内では締め切りは6月30日で、やむを得ない事情があれば相談に応じるとしている。第3版は7月末までの申請として、公費解体14件、自費解体の償還10件を数える。このほか、建物とは言えないが生活環境の妨げになると町が判断した8棟も、公費で撤去する。

        法律の上では町

        計画によれば、災害廃棄物は一般廃棄物にあたり、処理するのは町である。そのうえで、ごみの量と島の処理施設の能力を考えると町だけでは対応が難しいとして、都の支援を受けることにした。町は2025年11月13日に都へ支援を求め、都が示した島外処理の仕組みを採った。12月25日には、町・都・東京都環境公社の三者で基本協定を結んだ。

        役割は次のように分かれる。町は島内でごみを分け、砕き、コンテナに詰め、港まで運ぶ。都は島内と島外の処理の全体を調整する。公社は町から島外処理をまとめて引き受け、船での輸送、都内での陸送、処理施設での処理を事業者に再委託する。6月末の時点で、船は伊豆七島海運、陸送は日本通運、木材の処理は東京ボード工業が受けている。

        国と都のお金

        計画は財源として、町の一般財源のほか、都の災害復旧事業と、国（環境省・国土交通省）の補助制度を挙げる。

        環境省の災害等廃棄物処理事業費補助金は、災害で出たごみの収集・運搬・処分の費用の2分の1を補助する。通常の災害では、残る地方負担の8割に特別交付税が配られる。この仕組みをそのまま当てはめると、補助の対象になる経費のうち町に残るのは1割ほどになる（本紙計算）。ただし第3版は、木くずのうち町が単独で行う事業の分と、倒木のうち都の八丈支庁が管理する分は補助の対象外と注記している。補助の額は国の査定で決まる。

        町は2026年6月11日に議会へ出した補正予算で、国の都市災害復旧事業の堆積土砂排除事業補助金8億78万円を新たに見込んだ。このうち7億4,789万円をごみ処理の費用（じん芥処理費）に充て、その分の町の一般財源を減らしている。土砂を取り除くための補助金が、災害廃棄物の処理にも使われている。

        都は、2025年度の最終補正予算案に「島しょ地域における災害廃棄物処理支援事業」として28億3,300万円を計上した（2026年2月の都議会での説明。予算案の額）。また都は、公社が事業者に毎月払う費用を、町から支払いを受けるまでつなぐため、公社に約30億円を貸し付けている（2026年6月の都議会での答弁）。2026年3月末の公社の借入残高は0円だった。

        町の予算

        町の2026年度一般会計の予算書から、災害廃棄物と被災家屋の解体の行を本紙が合計すると、9月の第3号補正までで57億2,118万円になる。町長は3月の施政方針で、島外搬出処理事業や公費解体などに約57億円を計上したと述べていた。

        • 片付けごみ:町の許可証を見せれば、回数と量の制限の範囲で無料。許可証がなければ、ふつうの粗大ごみとして有料になる
        • 全壊した建物:公費解体なら、解体と撤去の費用はかからない。すでに自分で解体した人は、申請すれば費用の償還を受けられる。償還額の決め方は町の要綱による
        • 全壊でない建物:半壊や一部損壊の建物を取り壊したり直したりする費用は、この制度の対象にならない
